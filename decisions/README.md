# Architecture Decision Records

This directory contains Macro Evidence decisions that genuinely apply across multiple repositories or to the organization's structure itself. Repository-specific decisions belong in that repository's own `decisions/` directory.

The shared ADR contract, including placement, numbering, filenames, references, lifecycle metadata, required structure, decision-boundary grammar, and index behavior, is defined in [`DOCUMENTATION_STANDARDS.md`](../DOCUMENTATION_STANDARDS.md) §5.
